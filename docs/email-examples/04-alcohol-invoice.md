# Алкогольная накладная (ЕГАИС)

Статус: **Алкоголь** 🍺 — считаем обработанным (ручной ввод в DocsInBox невозможен).

```
Здравствуйте! 😊

Ручной ввод не подходит для алкогольных накладных, потому что отчётность по алкоголю ведётся через ЕГАИС, и обработка накладных, внесённых вручную, в этом случае будет невозможна. 

Если вы не получили алкогольную накладную от поставщика, попробуйте перезагрузить компьютер на котором установлен УТМ, и провести обмен данными с ЕГАИС и повторно сделайте обмен через 15–20 минут.

Если это не поможет, пожалуйста, напишите в техническую поддержку.
Это можно сделать:
- По телефону: +7 (800) 100-87-30;
- Через кнопку «Поддержка» → «Написать в поддержку» в шапке сайта;
- В мессенджере Telegram: @Docinbox_bot
```
