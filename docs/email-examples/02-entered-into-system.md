## Действия бота

1. Найти строку реестра по **№ обращения** (статус **Получено системой**).
2. Дописать в реестр: ссылку `dxbx.ru`, № `СП…`, id `79448515`, дату документа.
3. Сменить статус → **Внесено**.
4. Поставить реакцию ✅ на якорное сообщение в чате.
