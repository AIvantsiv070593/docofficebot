# Входящее письмо: документ уже есть в системе

Статус заявки после этого письма: **Внесено** (👍).

DocsInBox отвечает так, когда накладная **уже была выгружена** раньше — новой обработки нет, но в письме есть ссылка dxbx.

В реестр: записать ссылку (и № документа), **только если колонка «Ссылка» ещё пустая**. Статус → **Внесено**.

## Реквизиты

| Поле | Значение |
|------|----------|
| От | `invoice@docsinbox.ru` |
| Кому | `theofficesakh@gmail.com` |
| Тема | `ООО Сфофрендз инн 6501291591\ ИП БАТУРИН, №2744` |

> Тема ответа **та же**, что у исходящего.  
> В теле № обращения **нет**.  
> Матчинг: заявка со статусом **Письмо отправлено** или **Получено системой** по **полной теме** или reply-цепочке (этот ответ может прийти без письма «обращение №…»).

## Пример тела

```
Здравствуйте! 😊

Документ уже есть в системе и доступен ниже по ссылке :) 

Хорошего дня!  ❤️

---

Документ 56241 от 12.10.2026 00:00 ранее был выгружен в систему: https://dxbx.ru/index#app/edit/invoice/79448310




С уважением,
Команда распознавания документов DocsInBox
```

## Парсинг

| Что | Как |
|-----|-----|
| Маркер этапа | «Документ уже есть в системе» и/или «ранее был выгружен в систему» |
| № документа | `56241` |
| Дата документа | `12.10.2026` (время `00:00` можно игнорировать) |
| Ссылка | `https://dxbx.ru/index#app/edit/invoice/79448310` |
| ID в системе | `79448310` (из пути `/invoice/{id}`) |

## Действия бота

1. Найти строку реестра по **полной теме** / thread (статус **Письмо отправлено** или **Получено системой**).
2. Если ссылки в реестре ещё нет — дописать dxbx-URL и № документа.
3. Сменить статус → **Внесено**.
4. Поставить реакцию 👍 на якорное сообщение в чате.
5. Удалить локальные вложения заявки (как при обычном «Внесено»).
