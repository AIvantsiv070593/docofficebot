# Входящее письмо: документы получены системой

Статус заявки после этого письма: **Получено системой** (📥).

Из тела извлекается **№ обращения** и пишется в Google Sheets.

## Реквизиты

| Поле | Значение |
|------|----------|
| От | `invoice@docsinbox.ru` |
| Кому | `theofficesakh@gmail.com` |
| Тема | `ООО Сфофрендз инн 6501291591\ ИП БАТУРИН, №2744` |

> Тема ответа **та же**, что у исходящего письма (префикс организации + `\ ` + контрагент и номер накладной).  
> По полной теме бот однозначно находит заявку в реестре.

## Пример тела

```
Здравствуйте!😊
Мы зафиксировали ваше обращение №059137937
Документы будут обработаны до 24-х часов.
Как только всё будет готово, мы обязательно вас оповестим.

Чтобы мы могли обработать документы как можно быстрее, пожалуйста, убедитесь, что:

- ✓ изображения чёткие и хорошо читаются;
- ✓ все позиции накладной хорошо видны;
- ✓ документ полностью помещается в кадр;
- ✓ если документ состоит из нескольких страниц, отправлены фотографии всех страниц.

Это поможет ускорить распознавание и быстрее добавить данные в систему DocsInBox.

Благодарим за сотрудничество!

Хорошего дня!

---
С уважением,
Команда распознавания документов DocsInBox
```

## Парсинг

| Что | Как |
|-----|-----|
| Маркер этапа | фраза `зафиксировали ваше обращение` |
| № заявки / обращения | `№059137937` → группа цифр после `обращение №` |
| Пример regex | `обращение\s*№\s*(\d+)` |

## Действия бота

1. Найти строку реестра со статусом **Письмо отправлено** (матчинг: FIFO / In-Reply-To — по правилам реализации).
2. Записать № обращения (`059137937`) в колонку реестра.
3. Сменить статус → **Получено системой**.
4. Поставить реакцию 📥 на якорное сообщение в чате (`chat_id` + `message_id`).
