## Исходящее (для справки)

| Поле | Значение |
|------|----------|
| Кому | `invoice@docsinbox.ru` |
| От | `theofficesakh@gmail.com` |
| Тема | `ООО Сфофрендз инн 6501291591\ {контрагент+номер накладной}` |
| Тело | `Внести` |
| Вложения | файлы альбома из Telegram |

Тема исходящего уникальна за счёт хвоста после `\`.  
**Ответы DocsInBox — с той же полной темой.**

Матчинг:

1. Письмо «обращение №…» (номера ещё нет в БД) → **полная тема** (+ запас thread).
2. Записали № обращения в БД.
3. Письмо «внесено» / «уже есть в системе» (в образце № в теле нет) → заявка «Отправлено» или «Получено» по **теме** или **reply-цепочке**; если № в письме появится — только по нему. Ссылку в таблицу писать, только если её ещё не было.
4. Письмо про алкоголь / ЕГАИС → статус **Алкоголь** 🍺 (финал, как «Внесено»).
