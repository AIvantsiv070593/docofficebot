# Сайт для Google OAuth (GitHub Pages)

Публичный URL после включения Pages:

- Homepage: `https://aivantsiv070593.github.io/docofficebot/`
- Privacy: `https://aivantsiv070593.github.io/docofficebot/privacy.html`

## Включить Pages

GitHub → репозиторий → **Settings** → **Pages** → Source: **Deploy from a branch** →
ветка `main`, папка `/docs` → Save.

## Файл подтверждения Google

1. В Google скачай HTML-файл вида `googleXXXXXXXX.html`.
2. Положи его **сюда**, в каталог `docs/` (рядом с `index.html`).
3. Закоммить и запушь.
4. Открой в браузере:
   `https://aivantsiv070593.github.io/docofficebot/googleXXXXXXXX.html`
5. В Google нажми «Подтвердить».

В OAuth consent screen укажи те же Homepage / Privacy policy URL.
