# E2E чеклист перед боевым чатом

Выполнять в **тестовом** `ALLOWED_CHAT_ID`, затем переключить на ОФИС_Документы.

## Подготовка

- [ ] Privacy mode бота: Disabled
- [ ] Бот может ставить реакции
- [ ] Google OAuth пройден (`data/gmail_token.json`, scopes Gmail+Sheets)
- [ ] Таблица доступна аккаунту GMAIL_USER; листы «Лист1» и «Исключения»
- [ ] `.env` заполнен, `docker compose up -d --build` или `python -m src.main`

## Сценарии

1. **Один JPEG, подпись `/send ИП … №…`** → 👀 → ⚡, строка в Sheets, письмо на invoice@…
2. **Альбом 3 файла, `/send …` только в подписи первого** → одно письмо со всеми вложениями
3. **Реплай `/send ИП … №…` на фото** → 👀 → ⚡
4. **Контрагент из «Исключения»** → 🙈, письма нет
5. **PDF / чужой тип** → 👎 + DM админу
6. **Только `/send` без контрагента** → 👎
7. **Форвард** → игнор
7. **Ответ DocsInBox «обращение №»** (та же тема) → 🤝, номер в Sheets
8. **Ответ «обработана»** → 👍, СП/ссылка, папка `data/claims/{id}` удалена
8b. **Ответ «документ уже есть в системе»** → 👍, ссылка в Sheets (если пусто), папка удалена
9. **Искусственный Gmail fail** (отозвать token) → DM админу, новые заявки 👎 `Gmail auth`
