## [1.1.0] — 2026-10-30

### Добавлено

- Поддержка **PDF** во вложениях; сжатие до лимита письма (PyMuPDF → при необходимости страницы в JPEG).
- Ответ DocsInBox про **алкоголь / ЕГАИС** → статус «Алкоголь», реакция 🍺, заявка закрыта.
- Админ-команды:
  - `/retry`, `/retry_errors` — переотправка заявок со статусом «Ошибка»
  - `/purge_errors CONFIRM` — удалить все «Ошибка» из БД + папки, затем resync Sheets
  - `/excluded` — заявки со статусом «Исключение»
  - `/alcohol ID` — вручную закрыть заявку как алкоголь
  - `/exceptions`, `/exception_add`, `/exception_del` — справочник исключений в Sheets
- GitHub Pages: homepage + privacy для Google OAuth; `LICENSE` (MIT), `PRIVACY.md`.
- Пример письма: `docs/email-examples/04-alcohol-invoice.md`.

### Изменено

- `/pending` больше не показывает «Исключение» (и «Алкоголь»).
- Повтор `/send` при той же теме письма **чинит** старую «Ошибку», а не создаёт вторую запись.
- Реплай `/send` на сообщение с «Ошибкой» переиспользует ту же заявку.
- Проверка Gmail auth — **после** скачивания вложений (чтобы `/retry` имел файлы).
- Нормализация исключений: кавычки и пунктуация не мешают матчу (`ООО "Гильдия"` ≈ `ООО Гильдия`).
- Очистка orphan-папок **не** удаляет каталоги заявок в статусе «Ошибка».
- Backup-контейнер: запуск скрипта через `sh` (без требования `+x` на Windows/tar).

### Исправлено

- Тихий отказ `/send` на reply/forward-медиа при явной команде.
- Unique `dedupe_key` блокировал повторную отправку после «Ошибка».
